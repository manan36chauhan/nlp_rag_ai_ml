# nlp_rag_ai_ml

# Big Data Analytics & Prediction Projects

This repository contains two academic projects completed during my Master’s studies, focusing on **Big Data Analytics**, **Machine Learning**, **Prediction Methods**, and **Retrieval-Augmented Generation (RAG)** using Python.

---

## Projects Overview

### 1. Retrieval-Augmented Generation (RAG) – Big Data Analytics  
**Course:** M508B – Big Data Analytics

**Objective**  
Build a RAG pipeline to improve question answering by combining document retrieval with language model generation.

**What I Did**
- Preprocessed and chunked unstructured text data  
- Generated vector embeddings  
- Stored and queried embeddings using a vector database  
- Retrieved relevant context for user queries  
- Generated context-aware answers (RAG pipeline)  
- Evaluated relevance and response quality  

**Technologies**
- Python, NLP  
- Vector embeddings & vector database  
- Jupyter Notebook  

**Key Learnings**
- End-to-end RAG architecture  
- Efficient handling of large text data  
- Improving LLM outputs with external knowledge  

---

### 2. Methods of Prediction  
**Course:** M507B – Methods of Prediction

**Objective**  
Apply statistical and machine learning models for prediction and forecasting.

**What I Did**
- Exploratory Data Analysis (EDA)  
- Data cleaning and preparation  
- Implemented multiple prediction models  
- Compared statistical vs ML approaches  
- Evaluated models using appropriate metrics  
- Visualized predictions and errors  

**Technologies**
- Python  
- Pandas, NumPy  
- Scikit-learn  
- Matplotlib  

**Key Learnings**
- Prediction and forecasting techniques  
- Model comparison and evaluation  
- Translating analytical results into insights
